# Contractor Canvas

I am creating a premium reusable website template for established local hardscaping, landscaping, outdoor-living, and landscape-construction contractors.

This first implementation is a personalized website concept for:

Friendly Pro Landscapes

Greensboro, North Carolina

IMPORTANT PROJECT GOAL:

This is not intended to be a one-off custom-coded website.

Build this project as a reusable contractor website system so that I can later duplicate the project and replace the business information, photos, services, reviews, service areas, branding, and contact information for another contractor without redesigning the entire website.

Approximately 80% of the design and component structure should be reusable and approximately 20% should be business-specific personalization.

DESIGN DIRECTION:

Create a professional, premium local contractor website.

It should feel like a successful established contractor performing substantial residential outdoor projects — not a lawn mowing company, generic landscaping template, SaaS website, or flashy marketing-agency landing page.

The design should communicate:

- trustworthy

- established

- skilled craftsmanship

- high-quality outdoor work

- local

- approachable

- premium but not luxury-for-luxury's-sake

Use large authentic project photography as the primary visual element.

Avoid:

- excessive animations

- gradients everywhere

- oversized text

- generic AI illustrations

- fake statistics

- fake awards

- fake reviews

- stock photos when authentic project images are supplied

- excessive rounded cards

- overly trendy SaaS-style layouts

- gimmicky effects

The website should prioritize conversion without feeling aggressive.

PRIMARY CONVERSION ACTIONS:

1. Request a Consultation / Request an Estimate

2. Call the business

On desktop and mobile, the phone number must be clickable.

On mobile, make the primary actions exceptionally obvious.

HOMEPAGE STRUCTURE:

1. HEADER

Clean navigation.

Business logo/name.

Services.

Projects.

About.

Service Areas.

Contact.

Visible phone number.

Primary "Request a Consultation" button.

2. HERO

Use an outstanding real Friendly Pro project image.

Clear headline explaining what the company actually does and where they operate.

Short supporting statement.

Primary Request a Consultation button.

Secondary Call Now action.

Do NOT use vague headlines like "Transforming Outdoor Dreams Into Reality."

Use specific customer-centered language.

3. TRUST / REPUTATION STRIP

Communicate established local credibility using only factual information provided.

Include Google reputation/review information if provided.

Do not invent numbers or credentials.

4. CORE SERVICES

Feature the primary high-value services:

- Retaining Walls

- Drainage / French Drains

- Landscape Installation

- [additional service if supplied]

Each should have strong photography and concise benefit-driven copy.

Design these so each service can later link to a dedicated SEO service page.

5. FEATURED PROJECTS

Photography should be a major selling feature.

Create an attractive project gallery or featured-project section.

Do not make it look like a generic image grid.

6. WHY HOMEOWNERS CHOOSE FRIENDLY PRO

Create a concise credibility section using factual business information provided.

No invented claims.

7. REVIEWS

Use actual review excerpts I provide.

Create a tasteful review section emphasizing customer outcomes and trust.

8. SERVICE AREA

Clearly communicate Greensboro and the surrounding areas served.

Structure this so geographic/service-area content could later expand for SEO.

9. FINAL CTA

Strong project photography.

Simple call to action:

Planning an outdoor project?

Request a consultation.

Include phone and consultation button.

10. FOOTER

Business information.

Navigation.

Services.

Contact information.

Also include a small unobtrusive statement:

"Website concept prepared for Friendly Pro Landscapes. This is not the company's current official website."

FUNCTIONAL REQUIREMENTS:

- Fully responsive

- Fast loading

- Accessible color contrast

- Semantic heading structure

- Proper H1/H2 hierarchy

- SEO-friendly HTML

- Descriptive page title and meta description

- LocalBusiness / Contractor structured data architecture where appropriate

- Clickable phone numbers

- Functional navigation

- Strong mobile experience

- Optimize supplied images for web performance

- Do not index this demonstration website in search engines

- Add noindex,nofollow metadata while it remains a prospect demo

DEMO FORM:

Create a professional Request a Consultation form showing:

- Name

- Phone

- Email

- Project type

- Project description

Because this is currently a private concept website, DO NOT send the form to Friendly Pro Landscapes or imply that submissions are being received by them.

When submitted during the demo, display:

"This form is disabled on the demonstration website."

TEMPLATE ARCHITECTURE:

Where practical, centralize business-specific information so it is easy to replace for another contractor later.

Examples:

business name

phone

email

location

service areas

services

reviews

brand colors

hero copy

business description

social links

Create reusable components for:

Header

Hero

Trust section

Services

Projects

Reviews

CTA

Contact form

Footer

Do not hard-code business-specific information unnecessarily across many components.

FIRST TASK:

Build only the homepage initially.

Do not create the additional service pages yet.

Build a polished homepage that could reasonably convince an established contractor that this is substantially better than their existing website.

After creating the first version, stop so I can review it before making additional design changes.
